wasm-retro-cc

A WebAssembly toolchain that compiles C source into a classic Macintosh 68k MacBinary II APPL — entirely in your browser. Click Compile below to run the full pipeline on the bundled hello.c, then download the .bin and drop it into any classic Mac emulator. Source on GitHub — a fuller editor lives at classic-vibe-mac.

Wait — what's actually happening here? (explain it like I'm 10)

A "compiler" is a program that turns C code (what a programmer writes) into a real, runnable app. Normally, the compiler for old Macintosh apps only runs on a Mac. Even the modern ports only run on a Linux or macOS machine with a complicated setup.

What this page does: we took that compiler — actually four programs that work together — and we squished each of them down small enough to run inside a web page. Your browser is doing the same job a 1990s SE/30 with the right developer disks could do, except the developer disks weigh ~4 MB and arrive over the internet in a couple of seconds.

When you press Compile, the page runs your C source through this chain, all in your tab:

  1. cc1 — the C compiler from GCC — turns your C into assembly language for the Motorola 68000 chip a real classic Mac uses.
  2. as — the assembler from GNU binutils — turns assembly into machine code (an ELF object file).
  3. ld — the linker, also from GNU binutils — stitches your object together with the classic Mac runtime so it becomes a complete program.
  4. Elf2Mac — the file-format converter from Retro68 — repackages the result as a MacBinary II file, the wrapper a real Macintosh from 1989 knows how to launch.

The .bin you download is bit-for-bit the same kind of file you'd have gotten on a floppy in 1989 — drop it into any classic Mac emulator (Basilisk II, Mini vMac, SheepShaver, an actual old Mac) and it boots.

Who built the original compiler we packed into the browser?

Almost none of the heavy lifting in this project is ours. Massive credit to:

  • Retro68 — Wolfgang Thaller's open-source modern cross-compiler toolchain for classic 68k Macs. Retro68 is what made it even possible to compile C for 1989 Macs from a 2020s computer; we just re-wrapped it for the browser. The Elf2Mac step is Retro68's, and the GCC + binutils builds we ship are configured against Retro68's patches and Universal Headers.
  • GCC — the GNU Compiler Collection. cc1 here is GCC's C frontend, configured to emit m68k assembly.
  • GNU binutils — the assembler (as) and linker (ld) come from here.
  • Emscripten — the tool that compiled the four C/C++ programs above into the WebAssembly modules running in your browser tab right now.
  • Apple's original Universal Headers (the System 7-era Toolbox API declarations) — included via Retro68 so #include <Windows.h> resolves to the same definitions an 1990s Mac developer would have used.

What's ours: glue. The four-step in-browser pipeline driver (compile.mjs), the bundle packaging script that ships the sysroot as a single blob plus index, and the synthetic umbrella-header shims that smooth over the few spots the in-browser sysroot diverges from a native Retro68 install. Compared to the toolchains and 30 years of platform work above, our contribution is small but specific: the thing that lets all of it run in a web tab.
