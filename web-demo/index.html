wasm-retro-cc

A WebAssembly toolchain that compiles C source into a classic Macintosh 68k MacBinary II APPL — entirely in your browser. cc1 + as + ld + Elf2Mac, ~3.9 MB brotli total. Click Compile below to run the full pipeline on the bundled hello.c, then download the .bin and drop it into any classic Mac emulator. Source on GitHub — a fuller editor lives at classic-vibe-mac.
